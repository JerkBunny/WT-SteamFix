War Thunder × Steam 启动修复助手   [ 测试中 / Beta ]
====================================================

它干什么 / What it does
-----------------------
Steam 版战雷要更新 88 GB，但你已经有官方启动器下好的 25 GB 精简版。
本工具把精简版交给 Steam，直接开游戏，照常用 Steam 账号登录。
Steam wants 88 GB for War Thunder, but you already have the 25 GB minimal
client. This tool lets Steam launch it directly, and you keep signing in
with your Steam account.


三步 / 3 steps
--------------
1. 双击 WT-SteamFix.exe
   Double-click WT-SteamFix.exe
2. 第一屏按任意键（15 秒自动继续），之后一路回车
   Press any key on the first screen (auto-continues after 15 s),
   then press Enter for everything else
3. 看到「全部完成」就成了
   Done when you see "全部完成"

中途会有一屏「写入前检查」，列出目录、大小、关键文件、要改的记录，确认后再回车。
A "check before writing" screen shows the folder, size, key files and the
record it will change. Confirm with Enter.


客户端放哪儿 / Where the client goes  ★最重要
---------------------------------------------
Steam 只认这个名字，中间【有一个空格】：
Steam only accepts this exact name, WITH a space:

    <游戏库>\steamapps\common\War Thunder
    例 / e.g.  G:\SteamLibrary\steamapps\common\War Thunder

官方启动器默认装在 G:\WarThunder（没有空格），所以：
The official launcher installs into G:\WarThunder (no space), so either:

  放成 common\WarThunder（没空格）→ Steam 不认，工具会提示并帮你改名
  Dropped it into common\WarThunder (no space) → Steam ignores it;
  the tool warns you and offers to rename it

  复制内容进 common\War Thunder（有空格）→ 正确
  Contents inside common\War Thunder (with space) → correct

· 复制启动器文件夹【里面的所有内容】，不要多套一层
  （放好后 common\War Thunder\launcher.exe 应能直接看到）
  Copy what is INSIDE the launcher folder, don't nest it
  (common\War Thunder\launcher.exe must be directly visible)

· .launcher_log、.game_logs、cache 不用复制，复制了也无妨
  .launcher_log, .game_logs, cache are optional; harmless if copied


会关 Steam / Steam will be closed
----------------------------------
改安装记录前必须先关 Steam。工具会先提示、先备份，再关；存档不受影响。
Steam must be closed while the install record is rewritten. The tool warns
first, backs it up, then closes it. Saves are untouched.


记住 / Remember
---------------
· 不要点 Steam 的「验证游戏文件完整性」——会重新下 88 GB
  Never click "Verify integrity of game files" — it re-downloads 88 GB
· 战雷每次大更新后，重跑一次本工具
  After every major update, just run this tool again
· 被 Windows 拦下 → 更多信息 → 仍要运行
  Blocked by Windows → "More info" → "Run anyway"


出问题 / Troubleshooting
------------------------
· 没有写权限 / no write permission：右键 exe → 以管理员身份运行
  right-click the exe → Run as administrator
· 找不到 Steam / Steam not found：-SteamPath 指定 Steam 目录
  pass -SteamPath with your Steam folder
· 其它报错 / anything else：logs\diagnostic_*.txt 里有诊断报告
  a diagnostics report is in logs\diagnostic_*.txt


文件在哪 / Where files go
-------------------------
  logs\       日志 / logs
  backup\     改动前的 Steam 记录 / Steam record before each change
  snapshots\  快照，菜单 5 可还原 / snapshots, restore from menu 5
  .work\      临时文件 / temp
